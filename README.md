# Fierce Plugins

Internal plugin marketplace for Fierce Staffing Services and Consulting LLC.

## Setup (one time)

In Cowork: Customize → Plugins → Add marketplace → enter `https://github.com/rcarth/fierce-plugins`. Then install `fierce-coo-orchestrator` from this marketplace.

## Getting updates

When this repo is updated, click **Update** on the "Fierce Plugins" marketplace entry in Cowork → Plugins. No need to uninstall/reinstall.

## Plugins

- `plugins/fierce-coo-orchestrator` — Fierce COO Orchestrator. See its own README for details and changelog.
