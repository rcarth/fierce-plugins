# Labor Law Knowledge Base — moved

**This file is superseded as of 2026-09-03.** The canonical, agent-maintained Labor Law Knowledge Base now lives in the Fierce Second Brain on Google Drive: `memory/labor-law-knowledge-base.md` (file id `1Zf_3C0WZjC30l98J-zDZhThx3IgNJeispteOVshlQzQ`, inside the `memory/` folder id `1H4oJ8JgH2uzmZyK-QsFhPuMaS-Q0X7Jy`).

Why it moved out of the plugin repo: this is a living document `fierce-state-compliance` updates every time it researches a new jurisdiction. A copy bundled in this git repo would need a commit, a push, and (per the 3.6.2 changelog note above) a full plugin remove-and-reinstall from the marketplace just to pick up one new city profile. The Second Brain has no such friction, and it is also the one store that's readable on unattended/scheduled runs with no device connected, same reason FIERCE.md and the rest of `memory/` live there instead of in this repo.

This stub is safe to delete (`git rm plugins/fierce-coo-orchestrator/procedures/labor-law-knowledge-base.md`) whenever you're ready; nothing in the plugin references this path anymore, `fierce-state-compliance.md` points at the Drive file directly.
